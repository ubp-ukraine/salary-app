Підключи свій безкоштовний Supabase-проєкт для реального часу та синхронізації між командою.
Крок 1. Зайди на supabase.com → створи акаунт і новий проєкт.
Крок 2. У проєкті відкрий SQL Editor → вкопіюй SQL зі файлу schema.sql → виконай.
Крок 3. У Settings → General знайди Project URL (вигляду https://xxx.supabase.co). У Settings → API Keys скопіюй Publishable key (sb_publishable_...).
