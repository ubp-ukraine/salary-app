# Задачі та розрахунок

Внутрішній застосунок на трьох: трекер задач із бонусами + щомісячний розрахунок.

Ролі: Артем затверджує задачі й частки котла не бере; Діана та Єгор додають
задачі й ділять котел навпіл. Затвердження — відмітка стану: бонус іде
в проєктні незалежно від нього.

Виріс із однофайлового Task Tracker (`_incoming/task-tracker.html`), де підключення
до Supabase вводив користувач і воно лежало в localStorage. Тут інстанція зашита
на збірці, вхід — email + пароль.

## Як рахується місяць

Котел спільний: обидва фікси й проєктні складаються, і вже підсумок ділиться
за частками учасників. Тому 25 000 фіксу — це 12 500 на людину, а не 25 000 кожному.

| | |
|---|---|
| Фікс | 25 000 ₴ на двох, редагується по місяцях |
| Фікс за фікс багів | 25 000 ₴ на двох, редагується по місяцях |
| Проєктні | сума бонусів задач, у яких проставлений цей місяць |
| **Разом** | фікс + фікс за баги + проєктні, ділиться за частками (Діана і Єгор по 50%) |
| 15 числа | 10 000 ₴ на двох — константа, не редагується |
| В кінці місяця | решта, теж за частками |

Місяць у задачі проставляється **руками**: у вихідному трекері дати оплати немає,
а «коли закрили» не збігається з тим, за який місяць рахуємось.

## Запуск

```bash
npm install
cp .env.example .env     # підставити URL і anon key нашої інстанції
npm run dev              # http://localhost:5175
```

## Деплой

```bash
npm run deploy           # vite build + wrangler deploy (Cloudflare Workers)
```

## База

Supabase на тій самій ВМ, окремий блок портів 49000–49007
(«Оплати» займають 48000–48007). Схема — `supabase/migrations/0001_schema.sql`.
